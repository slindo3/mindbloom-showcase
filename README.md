# Mind Bloom — KSU Computing Showcase Website

Static HTML/CSS site published with GitHub Pages: https://slindo3.github.io/mindbloom-showcase/

- `index.html`: the site. The team chose the "Mind Bloom Story" design on 2026-11-16; the other two drafts are in Git history.
- `assets/screenshots/`: app screenshots taken with demo data only
- `assets/photos/`: team headshots, 400x400 WebP, named `first-last.webp`
- `team.json`: team details (name, role, graduation, interests, LinkedIn)

## Updating the site

Edit `index.html`, commit, and push to `main`. GitHub Pages republishes in about a minute. Keep links opening safely with `rel="noopener noreferrer"`, and never publish screenshots with real user data.
