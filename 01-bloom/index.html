01 / Our mission

What is Mind Bloom?

Mind Bloom is a full-stack web platform for the Mind Bloom Foundation, a nonprofit supporting mental health and wellness in the South Asian community. It replaces the foundation's static landing page with a multilingual community site.

Visitors can find events and resources, members can RSVP and save resources, and administrators can manage content without touching code. A 988 Suicide & Crisis Lifeline button is available on every page.

A thoughtful experience for every part of the community.

02 / What we built

Made for real people.

From exploring events to managing registrations, each feature supports a different community need.

✦

Explore events

Search upcoming workshops, support groups, and wellness events. Filter by category, date, and in-person or virtual, and switch between grid and calendar views.

✦

RSVP in a few clicks

Members RSVP with a guest count and preferred language, then track or cancel their RSVPs from a personal dashboard.

✦

Resource library

Search culturally tailored articles and guides by type and category, and bookmark favorites to come back to later.

✦

Support the mission

Donations, optional event donations, and paid-event tickets hand off to Zeffy. A wishlist shows items the community needs.

✦

Admin experience

Admins manage events, resources, users and roles, volunteers, the wishlist, translations, and legal pages, and can export registrations to CSV.

✦

Three languages

The interface is available in English, Hindi, and Gujarati, and event and resource content is stored per language.

05 / Technical approach

Built thoughtfully, end to end.

Next.js (App Router) with React and TypeScript renders pages on the server, styled with Tailwind CSS. Supabase provides the PostgreSQL database, authentication, and image storage.

Access rules live in the database as Row Level Security policies, so members only see their own RSVPs and only admins can change content. Every signed-in account finishes sign-in with an authenticator-app code (two-factor authentication).

Translations use next-intl, with event and resource text stored per language in PostgreSQL. Donations and paid events go through Zeffy, and email is sent through Resend. Database changes are tracked as versioned migrations and covered by pgTAP database tests.
